# Type-G Smart — عروض الكاميرات

تطبيق معاينات وعروض أسعار لشغل الكاميرات: الطلبات والمتابعة، المعاينة بالمكان والصور، حساب الخامات والكابل، وتنبيهات توافق الأجهزة، وعرض سعر PDF للعميل ونسخة داخلية.

- `www/` — التطبيق نفسه (يتنشر على GitHub Pages).
- `www/prices.enc` — قائمة الأسعار **متشفرة** (AES-GCM). بتتفتح جوه التطبيق بالرقم السري بتاع صاحب الشغل بس.
- `tools/prices.mjs` — تشفير وفك تشفير قائمة الأسعار.

بيانات العملاء والمعاينات بتتخزن على الموبايل بس، ومش بتترفع هنا.
